# auth-service

Сервис аутентификации ShopFlow: регистрация и вход пользователей, выпуск и проверка JWT. Остальные сервисы не проверяют токен сами, а обращаются к эндпоинту `/api/v1/token/introspect`.

## API
| Метод | Путь | Назначение |
|---|---|---|
| POST | /api/v1/auth/login | вход, выдаёт JWT |
| GET | /api/v1/users/{id} | данные пользователя |
| POST | /api/v1/token/introspect | проверка токена |
